# Jetpack News Shorts App
- News Shorts App Android Project, made with Jetpack Compose
- The application key aspects includes:
  - Jetpack Compose, Android's modern declarative toolkit for buiding native UIs
  - MVVM
  - Coroutines
  - Dependency Injection HILT
 
- Uses [NEWS API](https://newsapi.org/)
